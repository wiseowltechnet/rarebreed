# rarebreed

## Description
Development project and utilities

## Features
- Gradle build system
- Micronaut framework
- Spring Boot framework
- Pre-commit hooks for code quality

## Setup
```bash
git clone https://github.com/wiseowltechnet/rarebreed.git
cd rarebreed
./gradlew build
```

## Usage
```bash
./gradlew run
```
